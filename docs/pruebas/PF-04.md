# Prueba Funcional PF-04 — Consulta de evento inexistente o no publicado

- **Identificador:** PF-04
- **Épica origen:** E4 — Catálogo y consulta de eventos *(evidencias visuales completadas en `evidencias/PF-04/` en E8-A)*
- **Requisitos asociados:** RF-13, RN-01, RNF-07
- **Responsable:** Integrante A
- **Herramienta utilizada:** Cliente HTTP HTTPS (`TestClient` sobre `https://testserver` en `tests/test_catalogo.py`), navegador web y Swagger (`/docs`) sobre `https://127.0.0.1:8000`
- **Estado actual:** Ejecutada y aprobada (pruebas automatizadas y validación manual en Swagger e interfaz web con evidencias en `evidencias/PF-04/`)

## Condiciones iniciales

1. Base de datos SQLite temporal con eventos en estados `borrador` y `cancelado`, además de un identificador inexistente (`999999`).

## Casos cubiertos

### Caso PF-04.1 — API responde `404 EVENTO_NO_ENCONTRADO` uniforme
- **Método / Ruta:** `GET /api/v1/catalogo/eventos/{evento_id}`
- **Datos de entrada:** `evento_id = 999999`, ID de evento en `borrador` e ID de evento en `cancelado` (tanto anónimo como autenticado como organizador).
- **Pasos:**
  1. Enviar `GET /api/v1/catalogo/eventos/{id}` para cada caso.
  2. Inspeccionar código HTTP y estructura JSON de error.
- **Resultado esperado:** HTTP **404 Not Found** con `{"error": {"codigo": "EVENTO_NO_ENCONTRADO", "mensaje": "...", "detalles": []}}` en todos los casos, sin revelar si el ID existía como borrador o cancelado.
- **Resultado obtenido:** HTTP **404 `EVENTO_NO_ENCONTRADO`** uniforme verificado en `tests/test_catalogo.py::test_detalle_catalogo_retorna_404_si_inexistente_o_no_publicado`.
- **Estado:** Aprobada (automatizada en E4).

### Caso PF-04.2 — Vista web responde `404` con página amigable
- **Método / Ruta:** `GET /eventos/{evento_id}`
- **Datos de entrada:** `/eventos/999999` y `/eventos/{id_borrador}`.
- **Pasos:**
  1. Solicitar la vista web para un evento inexistente o no publicado.
- **Resultado esperado:** HTTP **404 Not Found** renderizando la plantilla amigable `catalogo/no_encontrado.html` con enlace para regresar al catálogo público (`/`).
- **Resultado obtenido:** HTTP **404** y texto `"Actividad no disponible"` verificados en `tests/test_catalogo.py::test_vistas_web_catalogo_detalle_y_404_amigable`.
- **Estado:** Aprobada (automatizada en E4).
